## What this is

Refine UI is the design system for our **internal tools**: time trackers, voting bots, dashboards, admin panels, the experiment you build on a Friday. It has one brand, [refine.studio](https://refine.studio): zinc neutrals, the refine teal accent, Geist, heavy display type, numbered sections and the diamond mark.

Refine UI is built for us, so it has a voice: gradients, glass, soft shadows and display type. [Principles](?path=/docs/foundations-principles--docs) lists the choices that give it that voice and the craft every component keeps.

## Using this Storybook

The **Mode** toggle in the toolbar switches every story and every specimen between light and dark. Check both: a component that looks right in only one mode is a bug.

## Install

Refine UI is published to the public npm registry as `@refine-studio/ui`. The install needs no token, and every version arrives already built:

```sh
pnpm add @refine-studio/ui
```

It expects React 19 and Tailwind CSS 4.

## Wire up the styles

Import the stylesheet after Tailwind. It brings the tokens, the Geist fonts and the animations, and tells Tailwind to scan the library's components.

```css
/* app.css */
@import 'tailwindcss';
@import '@refine-studio/ui/styles.css';
```

The stylesheet loads Geist and Geist Mono from `./fonts/`, next to itself, and a bundler such as Vite resolves them. When your build writes the CSS out by hand, copy one folder next to it:

```sh
cp -R node_modules/@refine-studio/ui/dist/fonts <your-css-folder>/fonts
```

## Wrap the app

`ThemeProvider` owns mode and density on `<html>` and remembers the choice in `localStorage`. See [Modes](?path=/docs/foundations-modes--docs).

```tsx
import { Button, ThemeProvider } from '@refine-studio/ui';

export const App = () => {
  return (
    <ThemeProvider mode="system">
      <Button variant="gem">Ship it</Button>
    </ThemeProvider>
  );
};
```

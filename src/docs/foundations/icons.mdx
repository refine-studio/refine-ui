# Icons

Refine UI draws every icon from the Refine icon set, kept in the shared [`@refine-studio/refine-icons`](https://www.npmjs.com/package/@refine-studio/refine-icons) package. It ships as a dependency, so there's nothing to install. Each icon is a React component named `RefineIcon` plus the icon's name: `Search_Magnifying_Glass` is `RefineIconSearchMagnifyingGlass`.

```tsx
import { RefineIconBell } from '@refine-studio/ui';

<RefineIconBell className="size-5" />;
```

The package draws its icons at a 2px stroke. Refine UI draws them at 1.75px. Every icon takes `className`, `size` and `strokeWidth`.

## By name

When the icon is data — a menu, a setting, a content field — pass its name to `Icon`. `IconName` lists every name, so a name the set lacks fails the type check.

```tsx
import { Icon, type IconName } from '@refine-studio/ui';

const items: { icon: IconName; label: string }[] = [
  {
    icon: 'House_01',
    label: 'Home',
  },
];

<Icon className="size-4" name={items[0].icon} />;
```

<IconByName />

The set leaves out raster 3D illustrations and multi-colour flags, because they cannot take the text colour. A new or fixed icon is drawn in the package ([refine-icons](https://github.com/refine-studio/refine-icons)), not here. Bump the package in `package.json`, add the new icon's line to `src/icons/refine-icons.ts`, and `pnpm test` fails until every package icon has one.

## Sizing

Components size the icons inside them from their own font size (`[&_svg]:size-[1.15em]` in `Button`), so you rarely set a size yourself. Outside components, match the text: `size-4` next to `text-body-sm`, `size-5` next to `text-body`.

## Icon-only buttons

Give them a visually hidden label and a `title` for the tooltip. Never `aria-label`.

```tsx
<Button size="icon" title="Search" variant="ghost">
  <RefineIconSearchMagnifyingGlass />
  <span className="sr-only">Search</span>
</Button>
```

Purely decorative icons need nothing: every Refine icon renders `aria-hidden` by default.

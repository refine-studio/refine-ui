# Typography

Geist and Geist Mono, shipped with the stylesheet. Headlines are heavy and tight, as on refine.studio; body text stays calm.

<Families />

## The scale

Use the scale names. Each one sets size, line height, tracking and, for display and headline, weight in one class.

<TypeScale />

Display sizes belong in headings. Keep them out of buttons, labels and data.

# Shape & spacing

## Radius

Four fixed radii, taken from refine.studio. Pick by the size of the thing, not by taste.

<RadiusTokens />

## Spacing

Refine UI keeps Tailwind's stock 4px scale: `p-4` is 16px and `gap-6` is 24px. Space with `gap-*` on flex and grid, not with margins.

## Control heights

Buttons, inputs and selects size themselves with `h-control-*`.

## Density

Density is the one size knob. Set `data-density` on any element, or `density` on `ThemeScope`, and every control height inside it scales.

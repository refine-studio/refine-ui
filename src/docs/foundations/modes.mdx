# Modes

Three modes, each a class you can put on any element: `.light`, `.dark` and `.on-gem`. `on-gem` is for white ink on the teal gradient, the mode of a brand panel or a celebration banner.

<ModeScopes />

## Scopes

`ThemeScope` re-themes one subtree without touching the page: a dark sidebar in a light app, or a compact pane next to a comfortable one.

<NestedScopes />

```tsx
<ThemeScope mode="dark">…</ThemeScope>
<ThemeScope mode="on-gem">…</ThemeScope>
<ThemeScope density="compact">…</ThemeScope>
```

## App theme

`ThemeProvider` applies mode and density to `<html>`, follows the operating system in `system` mode, and remembers the choice in `localStorage`. `ThemeSwitcher` is the ready-made light, dark and system toggle.

```tsx
import { ThemeProvider, ThemeSwitcher } from '@refine-studio/ui';

export const App = () => {
  return (
    <ThemeProvider density="comfortable" mode="system">
      <ThemeSwitcher />
    </ThemeProvider>
  );
};
```

### No light flash on load

`ThemeProvider` runs after the page starts, so a dark reader would see one light frame. `themeScript()` returns a small inline script for the page head. It applies the stored or the system theme before the first paint, and reads the same `localStorage` entry `ThemeProvider` and `ThemeSwitcher` write. Pass it the same `storageKey`, `mode` and `density` as the provider.

```ts
import { themeScript } from '@refine-studio/ui';

const head = `<script>${themeScript()}</script>`;
```

```tsx
<head>
  <script dangerouslySetInnerHTML={{ __html: themeScript() }} />
</head>
```

An app that stored a dark flag of its own passes `legacyStorageKey`. The script moves a `true` or `false` there to the new entry once, then deletes the old key:

```ts
themeScript({ legacyStorageKey: 'atlas:dark' });
```

Use `useTheme()` to build your own control:

```tsx
const ModeToggle = () => {
  const { resolvedMode, setTheme } = useTheme();

  return (
    <Button
      onClick={() => {
        setTheme({
          mode: resolvedMode === 'dark' ? 'light' : 'dark',
        });
      }}
      variant="ghost"
    >
      Toggle mode
    </Button>
  );
};
```
